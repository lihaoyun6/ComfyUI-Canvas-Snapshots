# ComfyUI-Canvas-Snapshots

在 ComfyUI 中为每个工作流标签保存多个状态快照并快速切换  

## 预览

<img src="./preview.png" style="height: 400px; width: auto;">

## 安装

#### 安装节点：
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/lihaoyun6/ComfyUI-Canvas-Snapshots.git
```

## 用法

- 安装插件后可点击 ComfyUI 工具栏中新增的相机图标来打开快照管理器.  
- 点击 <kbd>Capture Snapshot</kbd> 按钮来捕获当前画布状态, 即可随时返回到此状态.  
- 每个工作流标签页都拥有独立的快照空间, 关闭标签页将自动清空快照空间.
